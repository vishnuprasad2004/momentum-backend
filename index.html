How it works ?

Momentum is a AI powered Smart Notification system used for efficent Task Management. It is made using React Native and Expo SDK + framework for the app itself. It uses a Node.js + Supabase (PostgreSQL) backend to handle authentication, task storage, and notification generation. The notifications are powered by an AI model hosted on a separate server, which analyzes user behavior and task data to send timely and relevant reminders. It also features a gamified achievement system to motivate users to complete their tasks. The app authenticates users securely with JWT tokens and persists data across devices through Supabase’s hosted database and APIs.
